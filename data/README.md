# Data Contract

The public repo ships one benchmark file:

- `sample_prices.csv`

Columns:

- `date`
- `ticker`
- `sector`
- `close`
- `volume`
- `benchmark_close`

This is a structured public benchmark panel generated by [src/sample_data.py](../src/sample_data.py). It is not the original historical equity universe used in the Georgia Tech project.
