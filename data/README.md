# Data Contract

The public repo ships one benchmark file:

- `sample_prices.csv`

Columns:

- `date`
- `ticker`
- `sector`
- `close`
- `volume`
- `benchmark_close`

This is a structured public benchmark panel generated by
[src/sample_data.py](../src/sample_data.py). It is not the original historical
equity universe used in the Georgia Tech project.

Quick facts:

- `24` synthetic equities
- `6` sectors
- `4` names per sector
- `1,694` business dates
- date range `2019-01-02` to `2025-06-30`

For the full construction note, see
[reports/public_benchmark_data_construction.md](../reports/public_benchmark_data_construction.md).
